## Command-Line Windows instalation with unattend configuration file

1. Crate original Windows instalation media (Flash Disk)
2. Unzip this project to Flash disk
3. Boot Windows Setup from UEFI
4. Press SHIFT+F10 for Command-Line and start INSTALL.CMD
5. Set your oprions in script
6. Relax while automation instalation process
7. See your desktop? Finish!



## Structure
assets - include unattend configuration scripts, logo
In folder "usermod" include:
- Apps.txt - define your apps for instalation to new system
- wallpaper.jpg - custom wallpaper for set as default
install.cmd - start script
